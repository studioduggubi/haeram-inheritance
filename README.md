# 해람 상속 사이트

회생 사이트의 크림·세이지 색, Noto Sans KR/Noto Serif KR, 큰 섹션과 실제 인물·사무실 사진을 계승한 상속 전용 웹사이트입니다.

- Preview: https://studioduggubi.github.io/haeram-inheritance/
- 기존 상속·회생 운영 도메인과 분리한 개편 미리보기입니다.
- HTML/CSS/JavaScript 정적 사이트. 빌드 의존성이나 비밀 키가 없습니다.

## 실행

```sh
python3 -m http.server 4186 --bind 127.0.0.1
```

## 고객 흐름

실제 담당자 소개 → 5가지 상황별 안내 → 담당 역할·협업 범위 → 진행·견적 → 상담 메모 → FAQ → 네이버 예약·카카오톡·전화.

상황을 선택하면 안내와 준비 자료가 바뀌며, ‘이 상황으로 상담 준비하기’에서 메모의 주제가 이어집니다. 메모는 브라우저에서 생성하며 복사·텍스트 파일 저장이 가능합니다. 개인정보를 받거나 사무실로 자동 전송하지 않습니다. 카카오톡에 직접 붙여넣거나 예약·전화로 상담을 시작합니다. Google Sheets 등 회생 접수 백엔드는 연결하지 않았습니다.

## 운영 전환

현재 검색 로봇에는 noindex/nofollow 및 robots.txt 차단을 적용했습니다. 도메인 전환 시 메타·robots·OG URL·canonical·sitemap을 새 운영 주소에 맞춰 변경하세요. 기존 운영 사이트의 DNS/CNAME은 변경하지 않았습니다.

전문가 협업은 기존 상속 사이트에 공개된 이름·소속을 사용했습니다. 가격·처리 기간·성공률·후기는 창작하지 않았습니다. 상담료, 수임 범위, 협업 운영 문구는 사무실의 실제 운영 기준과 최종 대조해야 합니다.

## 이미지

실제 김해람 법무사 사진, 로고, 사무실 사진은 같은 브랜드의 회생 사이트 제작 자산을 재사용했습니다. 협업 전문가 사진은 기존 상속 사이트의 공개 사진입니다. 상속 전용 일러스트는 기존 해람 캐릭터를 참조해 내장 imagegen으로 생성했습니다. 원본·프롬프트·제작 근거는 클라우드 작업 폴더의 design/에 보관합니다.

## 검수

qa/VALIDATION.json에 실제 브라우저 검수 결과와 정적 파일 확인을 기록합니다. GitHub Pages는 main 브랜치 루트에서 배포합니다. 외부 예약·카카오톡의 로그인이나 고객 상담 접수는 해당 서비스에서 이루어집니다.
